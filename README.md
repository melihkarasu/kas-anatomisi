# 🏋️ İnteraktif Kas Anatomisi & Egzersiz

İnteraktif insan vücut haritası (ön ve arka görünüm), hedeflenen kas grupları, egzersiz kütüphanesi, doğru form video/talimat rehberi ve kişisel antrenman programı oluşturucu.

## ✨ Özellikler
- **Vektörel İnteraktif Anatomi Şeması:** Tıklanabilir ön ve arka vücut kas grupları (Göğüs, Sırt, Omuz, Biceps, Triceps, Karın, Quadriceps, Hamstrings, Glutes, Calves, Bel).
- **Zengin Egzersiz Kataloğu:** Ekipman (Vücut ağırlığı, Dambıl, Halter, Makara) ve zorluk seviyelerine göre filtrelenebilir hareket rehberi.
- **Doğru Form & Video Rehberi:** Her hareket için adım adım uygulama adımları, YouTube video gösterimleri ve sakatlık önleyici fizyoterapi tavsiyeleri.
- **Kişisel Antrenman Rutini Oluşturucu:** Seçtiğiniz egzersizlerle set, tekrar ve ağırlık planlaması; tahmini süre ve çalışan kas dağılımı.
- **Dışa Aktarma (Export):** Antrenman programınızı Yazdır/PDF, Markdown metin, Excel/CSV veya JSON dosyası olarak tek tıkla indirin.
- **%100 Sunucusuz & Çevrimdışı Çalışma:** Herhangi bir API anahtarı veya backend gerektirmez; tüm veri tarayıcı belleğinde ve LocalStorage'da işlenir.

## 🚀 Hızlı Başlangıç
1. Bu repoyu klonlayın:
   ```bash
   git clone https://github.com/melihkarasu/kas-anatomisi.git
   cd kas-anatomisi
   ```
2. `index.html` dosyasını doğrudan tarayıcınızda açın veya [GitHub Pages](https://melihkarasu.github.io/kas-anatomisi/) üzerinden canlı kullanın.
